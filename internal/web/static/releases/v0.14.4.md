CertSmith 0.14.4 is a security and maintenance release. It changes no behaviour and no settings; it is built
with a Go release that fixes a crash in the web server, and replaces two components that had published updates.

Upgrade with the command under Settings → Software. Settings and data are kept, and the previous version is
restored if the new one does not start.

## Security

- **Go 1.27.4.** The program is built with the Go release that fixes GO-2026-6859 (CVE-2026-97054) in the
  standard library (`net/http`). An oversized request to the web interface could, in rare timing, crash the
  server instead of being refused. CertSmith limits the size of every request to the web interface, so it was
  reachable there.
- **OpenTelemetry 1.47.0.** A library that some cloud DNS vendor clients bring in now enforces its attribute
  length limit for every kind of value. CertSmith does not use this library itself; it is updated so that the
  fix is not left waiting.

## Improved

- **Cryptography library `golang.org/x/crypto` 0.59.0**, with the system, text and sync libraries it depends on.

CertSmith 0.14.2 is a security and maintenance release. It changes no behaviour and no settings; it replaces
two components that had published security fixes.

Upgrade with the command under Settings → Software. Settings and data are kept, and the previous version is
restored if the new one does not start.

## Security

- **Go 1.27.3.** The program is built with the Go release that fixes GO-2026-6809 in the standard library
  (`crypto/x509`, which trusted certain compromised intermediate certificates). CertSmith reaches this code
  whenever it verifies a device's certificate, for example in **Test connection** and in the monitoring checks.
- **JOSE library 4.1.6.** The library the ACME client uses for JSON Web Keys now rejects RSA keys larger than
  4096 bits (GHSA-mgcc-cww5-fp2q). CertSmith creates keys of at most 4096 bits, so it was not affected in
  practice; it is updated so that the fix is not left waiting.

## Improved

- **ACME client updated to lego 5.6.0**, together with the cloud and DNS vendor libraries it depends on.
  None of the certificate providers in the list changes behaviour.

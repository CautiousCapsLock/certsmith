CertSmith 0.14.1 makes first setup harder to get wrong, and shows what an upgrade brings before you do it.
It does not change how certificates are issued or how your devices are updated; it is the interface and its
guard rails.

Upgrade with the command under Settings → Software. Settings and data are kept, and the previous version is
restored if the new one does not start.

## New

- **Release notes in the program.** Settings → Software has a **Release notes** button. It shows what this
  version brings and, when a newer release exists, what upgrading to it will change, in plain bullet points.
- **A checklist for first setup.** The Certificates, Targets and Certificate providers pages show
  "Set up in this order": provider, then certificate, then target. Each step is locked until the one before it
  exists, so nothing can be added out of order.
- **Copy button on the update command.** Settings → Software shows the command to run on the server with a
  Copy button next to it.
- **Install a certificate on CertSmith's own page in one step.** Choosing a certificate under Settings → HTTPS
  certificate installs it at once, and the card has a **Deploy now** (or **Redeploy**) button.

## Improved

- **Settings is easier to follow.** The cards in each section are indented under the section's heading, and
  **Send test alert** now sits in the Alerts section, where it belongs.
- **Settings warns before you lose changes.** Leaving the page, signing out or reloading with changes that
  are not saved asks first, and the page shows "Unsaved changes" while there are some.
- **Errors stay where you can read them.** A message from a dialog now stays in the dialog until you try
  again, and Save says what is missing (the name, a required field, a certificate) before anything is sent.
- **Adding a target before any certificate exists** only offers the types that need none (Monitor only and
  FortiClient EMS), and says why, instead of offering a choice that would be refused.
- **Long messages no longer push buttons around.** The Certificates heading keeps its buttons in place when
  Let's Encrypt is on staging.

## Fixed

- Saving a new target said "deploying shortly" although the first deployment is always started by you. It now
  says that nothing is installed until you press Deploy.
